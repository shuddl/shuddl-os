## What shipped — as a NEW worker, zero shipped-source edits
An MCP v1 server as **`workers/mcp`** — a fourth Cloudflare Worker (api · agents · translator · mcp) that reuses every existing gate via a **service binding** to the api worker, so a booking runs the identical server-side gates as a human/CSR.

- **OAuth 2.1 AS** (`oauth.ts`) — hand-rolled PKCE authorization-code AS; `client_id = pairing_id`, `client_secret = pairings.secret_ref`; fail-closed `NotConfiguredSecretResolver` (the live flip is CONFIRM-gated by binding the secret store). → an opaque token → `mintPrincipalJwt` (`principal.ts`): an HS256 `SessionClaims` JWT the api accepts, `sub="mcp:<pairing>"`, **tenant from `pairing.tenant_id` only, `role="ops"` bounded** (never finance/admin), 5-min exp, **never returned to the client**.
- **JSON-RPC dispatch + the mutation chokepoint** (`registry.ts`, `gate.ts`) — `tools/list`/`tools/call`; every mutating tool funnels through the explicit `DEFAULT_MUTATION_CHECKS = [confirm, caps]` chokepoint before `callApi`; `mutatingCallApi` throws if a write is attempted without the chokepoint clearing it (a mis-declared tool fails loudly, never silently unmetered).
- **Six tools** — `quote_freight` (parties+shipments+rate, stamps `refs.pairing`), `book_shipment` (**stops at `accept-quote`; the unchanged Booking agent produces the gated `booking.created`**), `track` + `get_document` (lens-gated reads, no raw D1), `approve` (matrix-gated — an `ops` principal cannot decide a finance-required approval), `dispute`.
- **Server-side caps** (`caps.ts`, `caps-meter.ts`, REQ-105) — spend/velocity/lane from `pairings.caps`, a per-pairing **`CapsMeter` Durable Object** (atomic `checkAndReserve`, idempotency-keyed), attributed to the **acting** `ctx.pairingId` (never `refs.pairing`), fail-closed, no-caps-default = **zero not infinite**. No new D1 table (a DO is not a table).
- **Confirm-before-money** (`confirm.ts`, REQ-108) — `book_shipment` requires `confirm.amount_cents == the SERVER-recorded quote.priced sell`; the model cannot self-authorize money movement.
- **Public JSON API + signed webhooks** (`rest.ts`, `webhooks.ts`, REQ-109) — a `/api/*` REST mirror that reuses the SAME dispatch/chokepoint (structural parity — a REST book is gated identically); svix-style HMAC-signed webhooks with a counterparty-safe payload whitelist, fail-closed delivery.
- **171 tests** (incl. the full tenant-isolation matrix + a hostile-prompt suite with a concurrent-book race).

## The no-bypass architecture (REQ-030) + hostile-prompt safety (the DoD)
A 204-style discipline: the mcp worker appends at most `quote.accepted` (via the api's accept-quote route); the unchanged Booking agent + DO `#enforceBooking` produce the gated `booking.created`. Caps, confirm, and gates are enforced in worker code keyed off the **OAuth-token `pairing_id`** — never a model-supplied field — and the client never holds the internal api JWT, so it cannot call `/v1/*` directly. Proven prompt-independent: smuggled `cap`/`caps`/`pairing_id`/amount args are inert; a hostile pairing cannot dodge its cap via another pairing's quotes (actor-attribution); concurrent books can't over-book (the DO mutex); a finance approval can't be self-decided; no internal field/JWT leaks.

## REQ-119 exit audit — CLEAR-TO-CLOSE
An 8-lens adversarial swarm (no-bypass, cap/hostile-prompt, OAuth, tenant isolation, redaction, idempotency, fail-open, additivity) → independent refutation. **Zero Critical/High.** Core safety properties all PROBED CLEAN. Three findings, all fixed additively (RED-first):
1. **F1 (Medium, fail-closed)** — caps reserved before confirm validated + a non-idempotent reserve (a confirm-rejected/retried book over-debited the meter — a self-DoS, never an over-book) → reordered `[confirm, caps]` + made the DO reserve idempotency-keyed.
2. **F2 (Low)** — a malformed non-array `lanes` silently disabled lane enforcement (fail-open) → `parseCaps` now refuses it (fail-closed).
3. **F3 (Low)** — a `/register` 400-vs-401 pre-auth pairing-enumeration oracle → collapsed to a byte-identical 401.
